# DevFlow 🚀

DevFlow is a frontend dashboard designed to help software engineers and Computer Science students organize their projects, tasks, learning roadmap, and notes in one place.

## Features

- Dashboard with statistics
- Task management
- Project management
- Learning roadmap
- Notes management
- Data persistence using LocalStorage
- Responsive design

## Technologies

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Git & GitHub
